# ✈️ Kekes_Voyage
Kekes_Voyage est une application dédiée à la gestion complète des voyages, offrant des fonctionnalités de réservation de vols, de gestion des informations passagers et d'exploration de diverses destinations. Cette documentation détaille la conception de la base de données du système, en suivant la méthode Merise, une approche structurée pour l'analyse et la conception de systèmes d'information.
